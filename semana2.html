Programación Orientada a Objetos

Ejercicios prácticos de Java con interfaz gráfica Swing: Calculadora de sueldos, inversiones, descuentos y gestión de empleados.

🗂️ Trabajos realizados

Ejercicio 01

Planilla de Vendedor

Programa que calcula la planilla de pago mensual de un vendedor. El sueldo básico es S/. 350.75, más una comisión del 5% del importe vendido. Se aplica un descuento del 15% del sueldo bruto por ley.

// Fórmulas principales comision = 0.05 * importeVendido; sueldoBruto = SUELDO_BASICO + comision; descuento = 0.15 * sueldoBruto; sueldoNeto = sueldoBruto - descuento;

Clase principal: AplicaBoleta.java

Entradas: Nombre del vendedor, Importe total vendido

Salidas: Sueldo básico, comisión, sueldo bruto, descuento, sueldo neto

Ejercicio 02

Distribución de Inversión en Feria

Programa que distribuye un monto total de inversión en seis rubros según porcentajes específicos: Alquiler (23%), Publicidad (7%), Transporte (26%), Servicios (12%), Decoración (21%) y Gastos varios (11%).

// Porcentajes establecidos alquiler = 0.23 * monto; publicidad = 0.07 * monto; transporte = 0.26 * monto; servicios = 0.12 * monto; decoracion = 0.21 * monto; gastos = 0.11 * monto;

Clase principal: AplicaFeria.java

Entrada: Nombre de la empresa, Monto total a invertir

Salida: Distribución detallada por cada rubro

Ejercicio 03

Venta de Camisas - Descuento 7% + 7%

Programa que calcula el descuento por temporada de verano denominado "7% + 7%". Se aplica un primer descuento del 7% sobre el importe de compra, y un segundo descuento del 7% sobre el saldo restante.

importeCompra = precio * cantidad; desc1 = 0.07f * importeCompra; desc2 = 0.07f * (importeCompra - desc1); descTotal = desc1 + desc2; importePagar = importeCompra - descTotal;

Clase principal: AplicaDescuento.java

Entradas: Nombre del cliente, Precio unitario, Cantidad de camisas

Salidas: Importe compra, Primer descuento, Segundo descuento, Descuento total, Importe a pagar

Ejercicio 04

Gestión de Sueldos por Categoría

Programa que calcula el sueldo de empleados según su categoría (A o B), horas trabajadas y número de hijos. La tarifa horaria es S/.45.00 para categoría A y S/.37.50 para categoría B. Bonificación por hijos: S/.40.50 (hasta 3 hijos) o S/.35.00 (más de 3 hijos). Descuento: 13.5% si sueldo bruto ≥ S/.3500, sino 10%.

// Tarifas por categoría Categoría A: tarifa = 45.0 Categoría B: tarifa = 37.5 sueldoBasico = horasTrabajadas * tarifaHoraria; bonificacion = (numHijos <= 3) ? numHijos * 40.5 : numHijos * 35.0; sueldoBruto = sueldoBasico + bonificacion; descuento = (sueldoBruto >= 3500) ? 0.135 * sueldoBruto : 0.10 * sueldoBruto; sueldoNeto = sueldoBruto - descuento;

Clase principal: GestionSueldo.java

Entradas: Categoría (A/B), Horas trabajadas, Número de hijos

Salidas: Sueldo básico, Bonificación, Sueldo bruto, Descuento, Sueldo neto
