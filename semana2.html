Unidad 1 · Semana 2

Clases, Objetos y Encapsulamiento

En esta semana se profundizó en la creación de clases y objetos en Java, aplicando el principio de encapsulamiento mediante modificadores de acceso y métodos getter/setter.

🗂️ Trabajos realizados

01

Modelado de clases con UML

Se elaboraron diagramas de clases UML para representar diferentes entidades del mundo real como Estudiante, Vehículo y Producto. Se identificaron atributos, métodos y la visibilidad de cada uno usando la notación estándar.

✓ Entregado
02

Implementación de encapsulamiento en Java

Se implementó una clase "CuentaBancaria" aplicando encapsulamiento: atributos privados (saldo, titular), métodos públicos para depositar y retirar dinero, y validaciones para evitar saldos negativos.

✓ Entregado
03

Ejercicios prácticos de instanciación

Se resolvieron ejercicios creando múltiples objetos a partir de una misma clase, comparando su comportamiento independiente. Se trabajó con arreglos de objetos y se mostró la información de cada instancia en consola.

✓ Entregado
