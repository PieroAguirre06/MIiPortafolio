Programación Orientada a Objetos

Ejercicio 01

Oferta de Tienda - Compra por Docenas

Programa que calcula el importe final a pagar por la compra de docenas de un producto. Aplica descuentos según la cantidad de docenas adquiridas y obsequia lapiceros según el importe a pagar.

📊 Reglas de negocio
Docenas adquiridasDescuento
≥ 10 docenas20%
< 10 docenas10%
🎁 Obsequio de lapiceros
Importe a pagar ≥ S/ 2002 lapiceros por cada docena
Importe a pagar < S/ 2000 lapiceros
// Fórmulas principales - Clase Tienda.java importeCompra = precioDocena * cantidadDocenas; if (cantidadDocenas >= 10) { descuento = 0.20f * importeCompra; // 20% } else { descuento = 0.10f * importeCompra; // 10% } importePagar = importeCompra - descuento; if (importePagar >= 200) { lapiceros = 2 * cantidadDocenas; } else { lapiceros = 0; }

Clase principal: CPrincipal.java

Clase de lógica: Tienda.java

Entradas: Precio por docena, Cantidad de docenas adquiridas

Salidas: Importe de compra, Importe del descuento, Importe a pagar, Cantidad de lapiceros de obsequio

Ejercicio 02

Venta de Pasajes - Ruta Lima - Huancayo

Programa que calcula el importe a pagar por la compra de pasajes de bus según el turno (mañana o noche). Aplica descuento sobre el importe de compra según la cantidad de pasajes y obsequia caramelos según el importe pagado.

🚌 Precios de pasajes
Turno MañanaS/ 37.50
Turno NocheS/ 37.50
📊 Descuento por cantidad
Cantidad de pasajes ≥ 158% de descuento
Cantidad de pasajes < 155% de descuento
🍬 Obsequio de caramelos
Importe por pagar > S/ 2002 caramelos por cada boleto
Importe por pagar ≤ S/ 2000 caramelos
// Fórmulas principales precioPasaje = 37.50f; // Mismo precio para ambos turnos importeCompra = precioPasaje * cantidadPasajes; if (cantidadPasajes >= 15) { descuento = 0.08f * importeCompra; // 8% } else { descuento = 0.05f * importeCompra; // 5% } importePagar = importeCompra - descuento; if (importePagar > 200) { caramelos = 2 * cantidadPasajes; } else { caramelos = 0; }

Clase principal: CPrincipal.java (paquete VISTA)

Entradas: Turno (Mañana/Noche), Cantidad de pasajes

Salidas: Importe de compra, Importe del descuento, Importe a pagar, Cantidad de caramelos de obsequio
