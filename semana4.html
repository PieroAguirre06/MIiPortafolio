Modelo - Vista - Controlador. Implementación de la arquitectura MVC en Java Swing.

📦 Oferta de Tienda con MVC

Programa que calcula el importe final a pagar por la compra de docenas de un producto, implementando la arquitectura MVC (Modelo-Vista-Controlador).

// MODELO: Tienda.java - Lógica de negocio calcularImporteCompra() { return precioDocena * docenas; } calcularDescuento() { return (docenas >= 10) ? 0.20 : 0.10; } calcularLapiceros() { return (importePagar >= 200) ? 2*docenas : 0; }

Clases: Tienda.java (Modelo), TiendaVista.java (Vista), TiendaControlador.java (Controlador)

Entradas: Precio por docena | Cantidad de docenas

Salidas: Importe compra, descuento, importe a pagar, lapiceros de obsequio
