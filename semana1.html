Ejercicio 01 y 02

Actividad Semana 1 — Cálculo de Descuento e Inversión en Feria

Dos aplicaciones Java con interfaz gráfica Swing. El primer ejercicio calcula el descuento por temporada de verano (7% + 7%) sobre la compra de camisas. El segundo distribuye una inversión en feria según porcentajes por rubro (alquiler, publicidad, transporte, servicios, decoración y gastos varios).

Curso

Taller: Desarrollo de Aplicaciones I

Docente

Mg. Fernandez Bejarano Raul Enrique

Ejercicio 01 — Entrada

Precio unitario y cantidad de camisas

Ejercicio 01 — Salida

Importe de compra, descuentos (7%+7%) e importe a pagar

Ejercicio 02 — Entrada

Monto total a invertir en la feria

Ejercicio 02 — Salida

Gastos en: alquiler, publicidad, transporte, servicios, decoración y gastos varios

Lógica principal — Ejercicio 01 (descuento 7% + 7%):

float importeCompra = precio * cantidad; float desc1 = 0.07f * importeCompra; float desc2 = 0.07f * (importeCompra - desc1); float descTotal = desc1 + desc2; float importePagar = importeCompra - descTotal;

Lógica principal — Ejercicio 02 (distribución por rubros):

float alquiler = PCT_ALQUILER * monto; // 23% float publicidad = PCT_PUBLICIDAD * monto; // 7% float transporte = PCT_TRANSPORTE * monto; // 26% float servicios = PCT_SERVICIOS * monto; // 12% float decoracion = PCT_DECORACION * monto; // 21% float gastos = PCT_GASTOS * monto; // 11%
